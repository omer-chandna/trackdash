# Contributing

Read [architecture](docs/architecture.md), [workflow](docs/development-workflow.md),
and [roadmap](docs/roadmap.md) before starting. The persistent engineering rules
are in [.cursor/rules/engineering.mdc](.cursor/rules/engineering.mdc).

Use Kotlin, focused interfaces, immutable state, and explicit errors. Prefer
test-first development for parsers, geometry, timing, alerts, and serialization.
Document physical-device checks separately from unit and emulator tests.
