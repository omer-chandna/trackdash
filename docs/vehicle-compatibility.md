# Vehicle compatibility

No vehicle or adapter has been tested. The initial physical target is a 2009 BMW
128i E82 with N52 engine. Generic standardized OBD-II must remain the default for
other compatible vehicles; BMW-specific providers are optional additions.

Capability discovery, response validation, manual vehicle profiles, and persistent
sensor availability are planned. Supported/unsupported/unavailable/stale/error are
distinct; missing values must never be replaced with zero or a healthy indicator.
